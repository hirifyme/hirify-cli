# hirify

Hirify CLI — доступ AI-агента к вакансиям [Hirify](https://hirify.me): фиды, поиск и «куда откликнуться».
Нужен тариф Pro и ключ: [hirify.me/account/api-access](https://hirify.me/account/api-access).

CLI — одна из **двух равноправных дверей** к одному и тому же API. Вторая — MCP
(`https://api.hirify.me/api/mcp`, тот же ключ в `Authorization: Bearer`). Обе first-party,
обе живут над одними сервисами: бери ту, в которой живёт твой агент.

```bash
npx hirify auth hirify_ВАШ_КЛЮЧ
npx hirify skill install     # скилл для Claude Code: правила и лимиты остаются с агентом

hirify me                    # план и остаток дневного лимита
hirify feeds                 # сохранённые фиды (это твои же фильтры с сайта)
hirify feed <id>             # вакансии по фиду         [--limit N]
hirify search "senior go"    # если подходящего фида нет [--limit N] [--grade G]
hirify reveal <slug>         # КУДА ОТКЛИКНУТЬСЯ — тратит 1 из 30 в день
```

Любая команда принимает `--json` — бери его для парсинга.

## Лимиты

- **Чтение бесплатно и без ограничений** (`me`, `feeds`, `feed`, `search`) — читай сколько нужно.
- **`reveal` тратит 1 из 30 в день** — это единственная платная операция.
- Повторный `reveal` той же вакансии **бесплатный** (дедуп на сервере).
- Лимит обнуляется в 00:00. Остаток всегда виден в `hirify me`.

Сначала отбирай чтением и раскрывай только подходящее: лимит стоит для живых людей
с агентами, а не для выкачки базы.

## Ключ

`hirify auth <ключ>` кладёт его в `~/.config/hirify/key` (права 600). Либо переменная
`HIRIFY_KEY` — она в приоритете. Ключ можно отозвать в кабинете в любой момент.

## Откликов нет

API отклика не существует и не планируется. CLI приносит ссылку и контакт — отклик
отправляет человек.

Требуется Node 18+. Зависимостей нет.
